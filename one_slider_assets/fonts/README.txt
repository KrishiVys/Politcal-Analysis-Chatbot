These complete open-source fonts are used by the app to render PNG images.
Keep this fonts folder inside one_slider_assets when uploading to GitHub.
No system font installation is needed for the app's PNG downloads.

For editable PowerPoint downloads, install these TTF files on the computer
where you edit the slides to prevent PowerPoint substituting different fonts.

The AP template uses Boston Angel Bold. The supplied PDF includes only a
subset of that font, so it cannot render arbitrary new headlines. Add your
licensed full font as BostonAngel-Bold.ttf or BostonAngel-Bold.otf in this
folder for an exact match. Until then, AP PNGs use the explicitly disclosed
Lora Bold fallback; the PowerPoint retains the Boston Angel font name.

Telugu text uses Noto Sans Telugu at the template's fixed point sizes and
matching weight because the original Latin fonts do not contain Telugu.

Open-source font licenses are included as the corresponding *-OFL.txt files.
